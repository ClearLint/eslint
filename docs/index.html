What is ClearLint?

ClearLint is a maintained fork of ESLint v9 that continues to receive security patches after the official ESLint v9 end-of-life on August 6, 2026. It is a drop-in replacement — if you use ESLint v9 today, you can switch to ClearLint with zero config changes.

ClearLint extends ESLint v9 with:

  • AI Guardrails — custom lint rules that catch common mistakes AI coding agents make (hardcoded secrets, insecure randomness, orphaned TODOs, missing error boundaries)
  • Audit-Assisting Reports — structured JSON reports that map code scans to security frameworks (SOC 2, ISO 27001), supporting your compliance narrative
  • Provenance — cryptographic hashes, timestamps, and signed manifests for every scan artifact
Important: ClearLint is a linting tool, not a compliance solution. It assists your team in documenting automated code scanning practices. Your organization and your external auditors determine what constitutes valid audit evidence for your compliance program.

Install ClearLint

ClearLint is a drop-in replacement for ESLint v9. Replace eslint with @clearlint/eslint in your project:

npm install @clearlint/eslint --legacy-peer-deps

Then update your npm scripts:

{
  "scripts": {
    "lint": "eslint ."  // unchanged — bin is still "eslint"
  }
}
Note: The --legacy-peer-deps flag is only needed during the transition period. Once you are fully on ClearLint, subsequent updates will not require it.
